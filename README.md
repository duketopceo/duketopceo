# Hey, I'm Luke

I build desktop tooling for **Omarchy** (Arch + Hyprland) and plugins for **Agent Zero**.

## Omarchy bar plugins

| Repo | What it does |
|---|---|
| [omarchy-plugins](https://github.com/duketopceo/omarchy-plugins) | Umbrella catalog + restore playbook for all `lukedaduke.*` plugins |
| [omarchy-fan](https://github.com/duketopceo/omarchy-fan) | RAM, CPU/GPU/NVMe thermals, top processes, and fan presets |
| [omarchy-ticker](https://github.com/duketopceo/omarchy-ticker) | Gold, tech, nuclear, energy, and rates in the bar |
| [omarchy-agents](https://github.com/duketopceo/omarchy-agents) | Claude Code, Codex, and Fireworks usage, limits, and pace |
| [omarchy-standby](https://github.com/duketopceo/omarchy-standby) | OLED nightstand overlay: clock, weather, red tint, caffeine |
| [omarchy-port-forward-plugin](https://github.com/duketopceo/omarchy-port-forward-plugin) | Toggle SSH port forwards from the bar |
| [blip](https://github.com/duketopceo/blip) | iMessage in the Omarchy bar via your Mac |
| [dayflow-linux](https://github.com/duketopceo/dayflow-linux) | Automatic local-first work journal with OpenRouter vision summaries |

Install any plugin: `omarchy plugin add https://github.com/duketopceo/<repo>`
