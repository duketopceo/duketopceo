# Hey, I'm Luke

I build desktop tooling for **Omarchy** (Arch + Hyprland), plugins for **Agent Zero**, and open-source agent infrastructure — orchestration, issue tracking, voice, and dictation.

## Now building

| Project | What it does |
|---|---|
| [agentflow](https://github.com/duketopceo/agentflow) | Cross-harness dynamic workflows: script-driven multi-agent orchestration for Devin, Claude, Codex, and OpenCode |
| [Tallyline](https://github.com/duketopceo/docketry) | Self-hostable, agent-native, MIT-licensed issue tracker with Linear-class UX |
| [open-computer](https://github.com/duketopceo/open-computer) | An open, self-hosted take on Perplexity Computer — research phase, architecture mapped, no runtime yet |
| [WordInk](https://github.com/duketopceo/WordInk) | Dictation as a component: provider-agnostic web SDK (pre-release). [Docs & demo](https://duketopceo.github.io/WordInk/) |
| [wisp](https://github.com/duketopceo/wisp) | Jev-routed voice computer-use agent for Omarchy — push-to-talk, act on screen, spawn background agents (v0.9 shipped) |

## Omarchy bar plugins

| Repo | What it does |
|---|---|
| [omarchy-plugins](https://github.com/duketopceo/omarchy-plugins) | Umbrella catalog + restore playbook for all `lukedaduke.*` plugins |
| [omarchy-fan](https://github.com/duketopceo/omarchy-fan) | RAM, CPU/GPU/NVMe thermals, top processes, and fan presets |
| [omarchy-ticker](https://github.com/duketopceo/omarchy-ticker) | Gold, tech, nuclear, energy, and rates in the bar |
| [omarchy-agents](https://github.com/duketopceo/omarchy-agents) | Claude Code, Codex, and Fireworks usage, limits, and pace |
| [omarchy-standby](https://github.com/duketopceo/omarchy-standby) | OLED nightstand overlay: clock, weather, red tint, caffeine |
| [omarchy-port-forward-plugin](https://github.com/duketopceo/omarchy-port-forward-plugin) | Toggle SSH port forwards from the bar |
| [blip](https://github.com/duketopceo/blip) | iMessage in the Omarchy bar via your Mac |
| [dayflow-linux](https://github.com/duketopceo/dayflow-linux) | Automatic local-first work journal with OpenRouter vision summaries |

Install any plugin: `omarchy plugin add https://github.com/duketopceo/<repo>`
